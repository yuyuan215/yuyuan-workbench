# 私人AI综合工作台 · 使用说明书

版本：v3.0　|　类型：纯静态网页系统（HTML + CSS + JavaScript，零后端依赖）

---

## 一、系统概览

| 项目 | 说明 |
|---|---|
| 运行方式 | 纯静态页面，托管到任意静态服务器 / 云平台即可 7×24 小时运行，与本地电脑开关机无关 |
| 访问方式 | 公网域名访问；内网部署（Nginx / IIS / 内部对象存储）亦可 |
| 登录鉴权 | 内置登录页，支持自定义账号 + 密码，多账号并存，会话 7 天免登录 |
| 数据存储 | 浏览器本地结构化存储（localStorage）+ 云端同步接口（可选开启） |
| 适配终端 | 电脑浏览器、手机浏览器自适应；手机端为抽屉式导航，触控友好 |
| 界面风格 | 低饱和度商务简约风，浅色默认，可一键切换深色模式 |

## 二、首次使用

1. 打开站点地址，进入**登录首页**。
2. 使用默认账号登录：

   - 账号：`admin`
   - 密码：`admin888`

3. 登录后 **立即进入「设置中心 → 账号与权限」修改密码**，并按需创建其他账号（如老板本人、助理各一个）。
4. 如需多设备同步（电脑 + 手机数据互通），进入「设置中心 → 云端同步」完成配置（见第五章）。

> 安全提示：账号密码经加盐哈希后存储，不保存明文。清空浏览器缓存会重置为默认账号，请提前用「导出全部数据」做备份。

## 三、界面与通用操作

- **左侧导航**：十大板块固定排列，一键切换；底部显示同步状态、立即同步、退出登录。
- **顶栏**：当前板块名称、深色/浅色切换按钮、当前登录账号。
- **手机端**：点击左上角菜单图标唤出导航，点击遮罩关闭。
- **键盘快捷键**（电脑端）：按 `1` ~ `9`、`0` 依次切换：待办 / 建立财商 / 英语学习 / 表达练习 / 每日运动 / 图书馆 / 美商提升 / **科学育儿** / 读书笔记 / 复盘查看。
- **每日自动刷新**：跨零点后（或重新打开页面时）自动加载当天的资讯、学习素材、跟练视频、荐书与选题，无需手动操作。
- **无弹窗设计**：所有编辑均为页面内嵌表单；删除类操作即时生效，重要的「清空缓存」需二次点击确认。

## 四、十大板块使用指引

### 板块 1｜今日待办

- **新增**：填写内容 → 选择分类 / 优先级 / 截止日期 / 状态 → 点击「添加待办」（内容框回车即可快速添加）。
- **自动分类**：标题包含「私人、体检、机票、孩子、礼品、接送」等关键词时，系统自动归入 **老板私人事务**，其余归入 **工作事项**；也可手动指定。
- **三色状态**：进行中（蓝）/ 已完成（绿）/ 延期（黄），点击对应按钮即可切换；**截止日期已过且未完成的事项会自动标记为「延期 + 已逾期」**。
- **编辑 / 一键清除已完成 / 当日汇总 / 顶部统计**：均在页面内完成，无弹窗打断。

### 板块 2｜建立财商

- **今日财经资讯**：每天自动推送多条精选内容（宏观、A股、基金、固收、心理等标签），支持「换一批」「快速阅读模式」。
- **每日财商视频**：内嵌 B 站高赞财商视频，页面内直接观看，也可「在 B 站打开」。
- **10 个深度名词 + 10 个创业案例**：每天轮换，案例支持点开长文阅读。
- **收藏**：任意内容点击「☆ 收藏」即归档到底部 **个人财商知识库**，支持筛选、检索、导出 TXT。

### 板块 3｜英语学习

- **每日英文课**：一个主题，包含核心词汇（含音标释义）、视频金句、实用短句、口语问答与今日任务。
- **每日 B 站英文视频**：内嵌播放，配合「影子跟读法」四步骤说明。
- **☆ 存为读书笔记**：金句一键写入「读书笔记」板块（自动归入「文学」笔记本）。
- **打卡 + 28 天日历 + 台账导出**：每次打卡计 30 分钟，可导出 CSV。

### 板块 4｜表达练习（中文）

- **每日中文素材**：央视新闻 / 百家讲坛 / 演讲等优质篇目，含跟读句、词语释义、好句赏析。
- **每日 B 站中文视频**：内嵌播放，练语感与表达节奏。
- **☆ 存为读书笔记**：好句一键写入「读书笔记」。
- **打卡 + 28 天日历 + 台账导出**：同英语学习。

### 板块 5｜每日运动（B 站跟练）

### 板块 6｜图书馆（原「亮灯自习室」）

- **每日热门书单**：参考 B 站 / 抖音热点书单，每天推荐 **5 本书**，附推荐理由与分类；点「换一批」立刻更换。

### 板块 8｜科学育儿

### 板块 9｜读书笔记（原「金句收藏夹」）

  1. 在「图书馆」任意一本书上点 **➕ 添加精选读书笔记**，填写「摘录 + 感想」；

### 板块 10｜复盘查看

- **切换周次**：「← 上一周 / 本周 / 下一周 →」随时回看历史周；点「导出复盘」保存为 TXT。

## 五、云端同步配置（可选，但推荐）

不配置时，数据保存在当前浏览器（离线可用）；配置后，多台设备（电脑 + 手机）自动共享同一份数据。

### 方式 A：JSONBin.io（零后端，最省事，推荐）

1. 打开 <https://jsonbin.io> 注册账号（免费额度足够个人使用）。
2. 进入 **API Keys**，复制 `X-MASTER-KEY`。
3. 点击 **Create Bin**，内容填 `{"v":1}` 后保存，从地址栏或详情页复制 **Bin ID**（形如 `65f1a2b3c4d5e6f7a8b9c0d1`）。
4. 回到工作台「设置中心 → 云端同步」：
   - 同步方式：`JSONBin.io`
   - Bin ID：粘贴上一步的 ID
   - Master Key：粘贴 API Key
   - 自动同步：开启
5. 点击「保存配置」→「测试连接」→「立即同步」。
6. 在第二台设备上登录同一站点，配置**相同的 Bin ID 与 Key**，即可自动拉取并合并数据。

### 方式 B：自定义 REST 接口

适合已有服务器或对象存储的场景。只需提供一个支持以下两种请求的地址：

- `GET  <接口地址>` → 返回之前保存的 JSON（首次可返回 404 或空）
- `PUT  <接口地址>` → 接收 JSON 请求体并覆盖保存

可选填「访问令牌」，系统会以 `Authorization: Bearer <token>` 头发送。

### 同步机制说明

- **合并策略**：按每条记录的 `updatedAt` 时间戳取新，不会互相覆盖整份数据。
- **删除传播**：删除采用「墓碑标记」，不会被其他设备的旧数据复活。
- **触发时机**：数据变更后 4 秒自动上传（防抖）、每 10 分钟定时同步、网络恢复时自动同步、点击「立即同步」手动触发。
- **离线可用**：断网时全部功能正常，数据留在本地，联网后自动补传。

## 六、数据管理与备份

「设置中心 → 数据管理」提供：

- **导出全部数据**：下载 JSON 备份（建议每月一次）。
- **导入数据（合并）**：与现有数据按时间戳合并，适合换设备迁移。
- **导入数据（覆盖）**：完全替换本机数据，适合恢复备份。
- **清空本机缓存**：需二次点击确认，清空后回到默认账号状态（云端数据不受影响）。

各板块另提供针对性导出：投资知识库（TXT）、语言学习台账（CSV）、运动记录（CSV）、选题储备库（CSV）。

## 七、常见问题

**Q1：换电脑或换浏览器后数据没了？**
数据默认存在浏览器本地。请开启云端同步，或用「导出/导入」迁移。

**Q2：忘记密码怎么办？**
静态系统无找回通道。可在浏览器中清空该站点的 localStorage（或使用「清空本机缓存」），系统会重建默认账号 `admin / admin888`；若已开启云端同步，请先在另一台已登录设备上修改密码。

**Q3：为什么「联网抓取」有时失败？**
实时抓取依赖第三方公共跨域代理，可能被网络策略拦截。失败不影响任何功能，系统会继续使用内置的每日精选内容。

**Q4：手机上添加到桌面可以吗？**
可以。使用浏览器「添加到主屏幕」，即可像 App 一样全屏打开。

**Q5：内网部署时登录提示加密方式不支持？**
浏览器仅在 HTTPS 或 localhost 下提供 `crypto.subtle`。纯 HTTP 内网环境会自动降级为内置哈希算法，功能正常；如需最高安全性，建议内网也配置 HTTPS。

**Q6：每日内容会重复吗？**
素材库按日期种子轮换，内置内容可覆盖约一个月不重复；点击「换一批」可在同一天内获取更多组合。素材库位于 `assets/js/data/content.js`，可自行扩充。

## 八、自定义扩展

- **增加每日素材**：编辑 `assets/js/data/content.js`，往对应数组追加条目即可，无需改动其他代码。
- **调整主题配色**：编辑 `assets/css/style.css` 顶部的 `:root` 与 `[data-theme="dark"]` 变量。
- **修改默认账号**：编辑 `assets/js/core.js` 中 `Auth` 模块的 `DEFAULT_USER` / `DEFAULT_PWD`（仅影响全新环境）。
